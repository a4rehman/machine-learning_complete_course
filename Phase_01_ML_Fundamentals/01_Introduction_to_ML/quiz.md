# Quiz: Introduction to ML

**1. What is the main difference between Traditional Programming and Machine Learning?**
A) Traditional programming uses Python, ML uses C++.
B) Traditional programming outputs rules, ML outputs data.
C) Traditional programming inputs rules and data to get answers; ML inputs data and answers to get rules.
D) There is no difference.

**2. Which of the following is an example of Unsupervised Learning?**
A) Spam detection (Spam / Not Spam).
B) Predicting the stock market price for tomorrow.
C) Customer segmentation (grouping users by behavior without predefined labels).
D) Teaching a robot to walk.

**3. What does the term "Training" mean in Machine Learning?**
A) Writing the code for the algorithm.
B) The process of the algorithm adjusting its internal weights/parameters to minimize error on data.
C) Downloading datasets from the internet.
D) Deploying the model to the cloud.

**4. In a supervised learning dataset, the outcome we are trying to predict is called the:**
A) Feature
B) Target / Label
C) Hyperparameter
D) Node

**5. True or False: Machine Learning algorithms can achieve 100% accuracy on new, unseen real-world data perfectly.**
A) True
B) False

---
### Answers
1. **C** (ML flips the paradigm, allowing algorithms to learn the logic).
2. **C** (Clustering/segmentation without labels is unsupervised).
3. **B** (Training is the optimization process).
4. **B** (Target, Label, or $y$).
5. **False** (Real-world data contains noise; a model with 100% accuracy is almost certainly "overfitting" or has data leakage).
