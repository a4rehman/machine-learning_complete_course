## 🌟 Platform Features

- **Interactive UI/UX**: A dark-themed, glassmorphism-powered Streamlit dashboard.
- **Dynamic Content Loading**: Auto-loads Markdown, Code, and Quizzes from the folder structure.
- **AI Playground**: Upload CSV files, automatically train models, and visualize feature importances directly in the browser.
- **FAANG Interview Prep**: Dedicated sections for system design and advanced ML interview questions.
- **Progress Tracking**: Built-in gamification, skill radars, and learning streaks.

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/Machine_Learning_Mastery.git
   cd Machine_Learning_Mastery
   ```

2. **Create a Virtual Environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch the Premium Dashboard**
   ```bash
   streamlit run app.py
   ```
